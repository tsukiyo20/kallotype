# FUJICOLOR NPH 400

The emulsion PRO 400H replaced, and the film whose scans the series measured PRO
400H's grain on. Measured in curves and sensitivities; dyes and mask borrowed.

- **The report:** [REPORT.md](REPORT.md) — the sheet, the fit, the anchor and what
  is borrowed rather than measured.
- **The film:** `fuji-nph400.kalofilm` (5,620 bytes) — load it with
  `kalo render --film-file`.
- **The points:** `curves/` — 664 points per layer.
- **The figures:** `figures/` — `01-curves`, `02-residuals`, `03-spectra`.

Headline numbers: γ 0.734 / 0.919 / 0.821 per decade; measured fields: curves, four layer sensitivities, grain.
