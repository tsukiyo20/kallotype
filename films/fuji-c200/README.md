# FUJICOLOR C200

The sheet drawn as 1-bit artwork: a sensitivity chart in five pieces, layer labels
painted over the curves, and the densest curve digitisation in the series.

- **The report:** [REPORT.md](REPORT.md) — the sheet, the fit, the anchor and what
  is borrowed rather than measured.
- **The film:** `fuji-c200.kalofilm` (5,920 bytes) — load it with
  `kalo render --film-file`.
- **The points:** `curves/` — 1137 points per layer.
- **The figures:** [01-curves](figures/01-curves.png), [02-residuals](figures/02-residuals.png), [03-spectra](figures/03-spectra.png).

Headline numbers: γ 0.612 / 0.646 / 0.669 per decade; measured fields: curves, layer sensitivities, MTF.
