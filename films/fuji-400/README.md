# FUJIFILM 400

The last stock in the catalogue: the same two charts as the 200-speed sheet, a
faster curve and the same three declared borrowings.

- **The report:** [REPORT.md](REPORT.md) — the sheet, the fit, the anchor and what
  is borrowed rather than measured.
- **The film:** `fuji-400.kalofilm` (5,498 bytes) — load it with
  `kalo render --film-file`.
- **The points:** `curves/` — 128 points per layer.
- **The figures:** `figures/` — `01-curves`, `02-residuals`, `03-spectra`.

Headline numbers: γ 0.578 / 0.635 / 0.638 per decade; measured fields: curves, layer sensitivities.
