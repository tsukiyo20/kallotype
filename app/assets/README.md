# Bundled marks

- `kallo-icon.png` — the 256 px mark the About page draws. It is written by
  `app/icon/generate.py` from `kallo-icon-1024.png`; do not edit it by hand.
- `github-mark.png` — GitHub's mark, used for the one link out of the app. The
  source is `app/icon/github-mark.svg`, from
  [Simple Icons](https://simpleicons.org) 16 (`CC0 1.0`). It was rendered at
  256 px and its white ground was turned into alpha so the interface can tint
  it with the current ink.
